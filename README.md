# Birthday Surprise Website 💗

A customizable single-page birthday surprise website.

## Open in Kiro

Open the **`birthday-surprise-kiro` folder** as your Kiro workspace/project.

Main file:
- `index.html` — all HTML, CSS, and JavaScript are currently self-contained here.

Assets:
- `assets/` — put photos, music, or other files here.

## Good first Kiro prompts

Try:

> Redesign this birthday website to feel more cinematic and romantic. Keep it mobile-friendly and make the animations smooth.

Or:

> Split the CSS and JavaScript into `style.css` and `script.js`, keeping the website behavior exactly the same.

Or:

> Add a photo gallery using images from the assets folder. Make the gallery elegant and responsive.

## Personalization

At the bottom of `index.html`, look for:

```js
const HER_NAME = "My Favorite Person";
const OUR_START_DATE = "2025-01-01T00:00:00";
```

Change these first.
