# Birthday Surprise Project

## Goal
Create a beautiful, personal, interactive birthday website for the user's girlfriend.

## Design direction
- Romantic
- Personal
- Premium / cinematic
- Mobile-first
- Smooth animations
- Easy to customize

## Important
Preserve working interactions when modifying the project.
Keep the site usable without a backend unless explicitly requested.
Prefer simple HTML/CSS/JavaScript unless a framework is specifically requested.
